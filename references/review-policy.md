# 六种状态与间隔复现

| 存储值 | 含义 | 证据 |
|---|---|---|
| not_learned | 未学习 | 学员确认未接触；不能因为缺少文件就断定 |
| exposed | 已接触但不理解 | 已讲解，含义仍未理解 |
| passive | 被动理解 | 能解释或识别，尚未独立使用 |
| prompted | 提示后使用 | 依赖意图、关键词或完整示范 |
| independent | 独立使用 | 未获目标提示，在新语境正确表达 |
| reconsolidate | 需要重新巩固 | 后续实际复测发现遗忘或误用 |

未观察是本次证据缺失，不是第七种掌握状态。不更新该知识点，不把没练到算失败。选择题正确最多支持被动理解；模仿不能升为独立使用。一次独立表达也不是永久掌握。

## 日期规则

首次有教学或表现证据的日期为 D，计划在 D+1、D+3、D+7 天复现。每轮使用不同场景。只有延迟的新场景中、无提示且正确的复测才推进一轮；同一天至多推进一轮。普通聊天中当天说对不会提前完成未来的复测。

复测依赖提示、误用或遗忘时，保留真实状态，复习轮次回到 0，次日再试；随后按这次日期的第 1／3／7 天重新安排。错过复习时先选到期重点，不补一堆旧课；通过迟到的一轮后，下一轮若原日期已过，至少隔一天再测。第 7 天轮通过后本轮结束；教师可安排更长期复习，本脚本不自动扩展。

脚本只执行按证据记录的日期规则，不能替教师判断日语是否正确。independent_correct 与 transfer 必须依据真实作答由教师填写。is_review 表示正式复测；刚讲完的即时练习应为 false。

本地数据只来自实际课程；due 读取独立记录后生成清单，不修改旧成绩。Project 无脚本能力时，在总结中列出同样的日期和轮次，人工保存并在下次提供。不能声称已自动安排通知。
